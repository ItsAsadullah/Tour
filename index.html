Not connected — নিচের ৪টি ধাপ অনুসরণ করে আপনার Google Sheet কানেক্ট করুন।
১ মিনিটে ফ্রি Google Sheet সেটআপ:
  1. নতুন একটি Google Sheet খুলুন (sheets.new) এবং নাম দিন (যেমন: Arkan Tour Expenses DB)।
  2. উপরের মেনু থেকে Extensions → Apps Script ওপেন করুন।
  3. আগের কোড মুছে উপরের Copy Apps Script Code বাটনে ক্লিক করে সম্পূর্ণ কোডটি পেস্ট করুন এবং Save (Ctrl+S) করুন।
  4. ডানপাশে Deploy → New deployment → Web app বাছুন, Execute as: Me এবং Who has access: Anyone দিয়ে Deploy করুন।
  5. পাওয়া Web app URL (শেষে /exec থাকে) নিচে পেস্ট করে Test & Connect চাপুন!
